## 🌱 Portal Ambiental

O Portal Ambiental é um sistema web desenvolvido para centralizar informações, serviços e conteúdos relacionados ao meio ambiente, promovendo sustentabilidade, conscientização e acesso facilitado a dados ambientais.

## 📌 Objetivo

O objetivo do portal é:

Facilitar o acesso a informações ambientais

Promover educação ambiental

Centralizar serviços e dados ecológicos

Incentivar práticas sustentáveis

Permitir interação entre usuários e o sistema

## ⚙️ Funcionalidades


- 🔐 Sistema de login e cadastro de usuários

- 🌍 Visualização de conteúdos ambientais

- 📄 Acesso a informações e serviços

- 📊 Organização de dados ambientais

- 📩 Possibilidade de contato ou envio de informações

- 📚 Área educativa sobre meio ambiente

## 🖥️ Tecnologias utilizadas

- PHP

- HTML5

- CSS3

- JavaScript

- MySQL (banco de dados)

- Servidor local (XAMPP/WAMP)
